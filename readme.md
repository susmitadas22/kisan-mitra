# 🌾 Kisan Mitra – Smart Farming App for Disease Detection & Alerts

**Kisan Mitra** is a mobile-first platform designed to empower farmers with early disease detection, real-time alerts, and community-based knowledge sharing.

## 📲 What It Does

- 📷 **Crop Disease Detection**  
  Farmers can click or upload crop images. The app analyzes them using a custom-trained transformer model and flags diseases.

- 📍 **Localized Alerts**  
  Sends real-time alerts to nearby farmers if a disease outbreak is detected.

- 🧪 **Fertilizer Stock & Inventory**  
  Tracks fertilizer availability and notifies local admins and farmers.

- 🤝 **Community Collaboration**  
  Enables knowledge sharing and support through real-time communication and scalable services.

## 🛠 Tech Stack

- **Frontend**: Expo (React Native)
- **Backend**: NestJS (Microservice Architecture)
- **ML Service**: Flask + Hugging Face Transformers
- **Infra**: Redis, PostgreSQL, Docker

## 🧠 Architecture Highlights

- Modular microservices for disease detection, inventory tracking, and real-time alerts.
- Seamless integration between mobile frontend and backend services.
- Scalable socket-based event system to push updates instantly.
